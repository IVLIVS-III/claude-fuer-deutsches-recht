Scheidungsfolgenakte der Eheleute Krammer in Passau mit Ferienwohnung, Depot, Praxisanteilen, mutmaßlich verschobenen Kryptowerten, Anfangsvermögen aus Erbschaft und streitiger Haushaltsgegenstände-Liste.
